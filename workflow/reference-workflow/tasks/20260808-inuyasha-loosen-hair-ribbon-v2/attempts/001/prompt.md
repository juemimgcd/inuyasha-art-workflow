# Generation specification

Use case: precise-object-edit
Asset type: edit
Selected medium: manga
Period mode: classic-balanced
Style strategy: three-layer-manga

Primary request:
第二次微调现有黑白漫画图：把犬夜叉后脑发绳的中心结和束发根部明显再放松一点，其他全部保持不变

Identity ledger:
- 犬夜叉 | 半妖形态 | 浅色长发、头顶犬耳、原图后脑束发 | 保持原脸与闭眼表情 | 保持火鼠裘和念珠 | 不新增武器 | 保持与桔梗的现有比例 | 不变成人类黑发、不要借用杀生丸特征

Input images:
- Image 1 `target`: 上一版无红框成品，是唯一编辑底图；只改后脑发绳及紧邻束发根部。
- Image 2 `style`: 只控制原著黑白漫画线条、黑白平衡和节制网点；忽略人物、动作、文字、布局和剧情。
- Image 3 `identity`: 只确认犬夜叉半妖形态的犬耳、浅色长发、脸部与念珠身份。
- Image 4 `continuity`: 只保持精选原创图已认可的构图、人物关系和完成度。

Scene/backdrop:
保持原图草地依偎场景和全部背景笔触、留白、草叶及网点完全不变。

Subject and exact moment:
犬夜叉闭眼依偎在桔梗身前，桔梗的手轻放在他的头上；人物与瞬间完全不变。

Composition/framing:
- 严格沿用 target 的 1123:1401 竖幅、裁切、透视、人物位置和负空间，不重新构图。

Medium construction:
保留现有经典黑白漫画印刷效果：有机锥形墨线、浅色头发以白色为主、桔梗黑发为完整黑块并带窄白高光、皮肤保持白色、服装使用原有网点密度。

Value/color plan:
纯黑白，不增加颜色、灰色涂抹、渐变、柔光或新网点；局部新线条必须与周围线宽和墨色一致。

Effects and setting:
不增加任何效果；保留原有细小草叶和背景点状纹理。

Constraints and invariants:
- 只修改犬夜叉后脑左侧可见发绳的中心结、两侧蝴蝶环、带尾与紧邻束发根部。
- 相比 target 再明显放松约 35%：中心结更饱满、更松软，不再像被拧紧的小硬结；中心结与发束之间出现很浅的松弛折痕或细小空隙。
- 让束发根部在结点两侧自然向外蓬开，消除被紧勒出的窄腰形收口；不要把头发拉紧成尖锐放射线。
- 两侧蝴蝶环略宽且向下垂，轮廓不对称但自然；两条带尾稍长、柔软下落，表现重力和松弛感。
- 发绳仍然稳妥系着，不要完全解开，不要删除发绳，不要让头发散开或改变马尾长度与整体轮廓。
- 保持犬夜叉的犬耳、额前发束、闭眼表情、脸部、念珠、服装和身体姿势完全不变。
- 保持桔梗的脸、头发、服装、腰带、身体、手掌、每根手指及接触位置完全不变。
- 保持所有背景、构图、裁切、线稿、黑白块面、网点和画面尺寸不变。
- 不生成红色标注框、文字、对话框、签名、logo 或水印。

Avoid:
- 不要仅仅放大蝴蝶结而让中心结继续紧缩；放松感必须主要体现在中心结和束发根部。
- 不要重画整张图，不要改变人物身份、画风、脸、手或任何未指定区域。
- 不要把发绳变成发夹、粗绳、现代橡皮筋或新饰品。
- 不要增加散发、改变犬耳、移动桔梗的手、改变接触位置或表情。
- 不要出现彩色动画质感、均匀矢量线、空气笔阴影、模糊或摩尔纹。
