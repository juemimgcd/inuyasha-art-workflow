# Generation specification

Use case: precise-object-edit
Asset type: edit
Selected medium: manga
Period mode: classic-balanced
Style strategy: three-layer-manga

Primary request:
微调现有黑白漫画图：只把犬夜叉后脑的发绳系松一点，其他全部保持不变

Identity ledger:
- 犬夜叉 | 半妖形态 | 浅色长发、头顶犬耳、原图中的后脑束发 | 保持原脸与闭眼表情 | 保持火鼠裘和念珠 | 不新增武器 | 保持与桔梗的现有比例 | 不变成人类黑发、不要借用杀生丸特征

Input images:
- Image 1 `target`: 唯一编辑目标；除后脑发绳结和紧邻发束外，整张图保持不变。
- Image 2 `style`: 只控制原著黑白漫画线条、黑白平衡和节制网点；忽略其人物动作、文字、布局和剧情。
- Image 3 `identity`: 只确认犬夜叉半妖形态的犬耳、浅色长发、脸部与念珠身份。
- Image 4 `continuity`: 只保持这张精选原创图已认可的构图、人物关系和完成度。

Scene/backdrop:
保持原图草地依偎场景和全部背景笔触、留白、草叶及网点完全不变。

Subject and exact moment:
犬夜叉闭眼依偎在桔梗身前，桔梗的手轻放在他的头上；人物与瞬间完全不变。

Composition/framing:
- 严格沿用目标图的 1123:1401 竖幅、裁切、透视、人物位置和负空间，不重新构图。

Medium construction:
保留现有经典黑白漫画印刷效果：有机锥形墨线、浅色头发以白色为主、黑发为完整黑块并带窄白高光、皮肤保持白色、服装使用原有网点密度。

Value/color plan:
纯黑白，不增加颜色、灰色涂抹、渐变、柔光或新网点；局部新线条必须与周围线宽和墨色一致。

Effects and setting:
不增加任何效果；保留原有细小草叶和背景点状纹理。

Constraints and invariants:
- 只修改犬夜叉后脑左侧可见的发绳结、蝴蝶结和紧邻的束发收口。
- 将束发结放松约 15% 至 20%：结点不再勒得很窄，绑住的发束在结点处稍微蓬松，蝴蝶结环更柔软、略大一点，带尾自然下垂。
- 发绳仍然系好，不要解开，不要删除蝴蝶结，不改变束发位置、马尾长度或整体头发轮廓。
- 保持犬夜叉的犬耳、额前发束、闭眼表情、脸部、念珠、服装和身体姿势完全不变。
- 保持桔梗的脸、头发、服装、腰带、身体、手掌与每根手指完全不变。
- 保持所有背景、构图、裁切、线稿、黑白块面、网点和画面尺寸不变。
- 不生成文字、对话框、签名、logo 或水印。

Avoid:
- 不要重画整张图，不要改变人物身份或画风。
- 不要把发绳变成新的饰品、发夹、粗绳或现代橡皮筋。
- 不要增加散发、改变犬耳、移动桔梗的手、改变接触位置或表情。
- 不要出现彩色动画质感、均匀矢量线、空气笔阴影、模糊或摩尔纹。
